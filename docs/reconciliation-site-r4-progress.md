# Site R4 本轮进展与验证边界

2026-10-22。本轮完成取消建单对账网页、严格运行配置、统一主站四模块与真实执行器 CLI 接入。原完整系统目标继续进行；当前运行环境未安装或切换，`idms.xin` 未备案，仍只进行部署准备。

## 已完成

原操作人可从预测设备中的原 `CANCELLED` 任务直达对账，按原命令找回已有记录。独立审批人可从当前设备范围目录进入，不依赖原操作人的本地编号。本人操作与本浏览器恢复编号分开显示；未知动作、未知授权均可按原控制编号查询或关闭。

R4 共享 R3 的审计会话认证。HTTP 配置只有 QI/READER；执行器使用 APP 和独立流程凭据。启动时核对权限、目录、部署、领域与密钥见证，不自动安装 schema。新授权围栏包装原 SQL 入口，旧入口也不能绕过已关闭编号。

浏览器实测修复了两项问题：未知 OPEN 原请求尚未确认时，按原命令阻止新 case 编号重复提交；后台详情轮询保持用户选中的恢复列表。完成状态会更新提示与当前记录的列表状态，已解决记录移出待处理列表。
