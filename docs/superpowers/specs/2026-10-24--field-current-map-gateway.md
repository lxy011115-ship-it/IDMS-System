# 当前现场网关接线

延续现场当前状态映射事务和平台依赖计划。当前签发/接收/查询内核已通过真实SQL验证；下一步必须运行实际OPC UA、mTLS MQTT和自有边缘进程，将业务ACK回到持久队列。不能以旧public-table网关或声明见证替代当前数据集的整链。

接收所有权使用同一当前PG中的专属会话锁，**实际写入事务使用持锁连接**。仅在另一条连接探测锁再提交，会留下探测与COMMIT间的失权窗口；因此不采用。只依靠进程内互斥也不能隔离其他实例。新所有者对实际数据库/角色OID、固定SQL目录和锁会话逐项核验，丢连接撤回所有权。排队写入不借用无所有权连接；未知提交只解析原SQL回执，失权后不返回ACK。

平台宿主复用现有私密配置/恢复材料加载，绑定当前企业账户、状态映射及显式guard。HTTP适配器保留机器HMAC、无Cookie/Origin、JSON白名单和容量/取消传播。MQTT适配器复用现有证书/材料/transport，只在当前所有者持锁时连接和接收，等待业务事务后发布签名ACK。关闭顺序是停止接入、排空/取消HTTP和MQTT回调、关闭接收/签发器、释放所有权，再允许PG停机；清理失败必须可见。

真实身份权威、冷恢复准入、严格enabled/descriptor/controller接线保持完整范围。本次QA的恢复文件/guard必须明确标注模型，不能当作已执行真正恢复或OIDC审批。历史查询HTTP/页面/预测消费、旧SQL现场数据迁移及全部原TODO也保持。

验证自有新PG、真实只读OPC UA、自有broker、真实edge fork及其实际退出/管道/IPC。覆盖所有权互斥、正常数据/队列确认、丢ACK补传原回执、原生读取消、持有SQL时关闭回滚、当前恢复或SQL围栏撤回后拒绝无操作重放，以及正常释放全部资源。双平台和GitHub管理后才能汇报相应范围成功。

实际网关验证暴露旧runner V3状态观察会调用有副作用的授权，撤销首次在途核对。用新SDK V2/只读客户端V2/runner V4/生命周期V3修复，旧922文件不变。状态观察只读取缓存的已验证租约及原墙钟/单调时钟截止时间；不得联网、延长两秒核对或撤销请求。真实操作仍执行签名与授权检查，停止/撤权仍取消HTTP。回归真实运行旧/新runner，在首次核对响应被持有时分别证明旧版被观察取消、新版等待显式停止；另核原两秒失效、错误profile撤销及实际HTTP取消。
