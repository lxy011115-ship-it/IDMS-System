# 读者密码阶段的私密签名恢复记录

接续已通过的SQL V4全部20项实际检查。V5增加跨进程的基线数据桥：只能由真实、尚未尝试且未过期的PREPARED SQL句柄导出完整实际目录、所有角色原密码、指定原新SCRAM值、原backend start/事务编号、准确目标与原期限。协调器须先将它持久保存，再允许阶段DDL或COMMIT。

记录使用独立域IDMS_CURRENT_DEPLOYMENT_READER_SQL_RECOVERY_V1 / SNAPSHOT和可信构造侧固定的32字节私密密钥认证。后续生产协调器须从已认证context取该密钥，外部请求不能提供密钥、记录或预期绑定。本层不替代原SOURCE/当前用户/持久安装意图及HMAC sibling日志。记录和全部验证器仅留私密文件；公开结果只有有密钥的记录MAC、编号、期限、计数和限定事实。

新进程加载记录时验证HMAC、完整结构、各表OID/角色/数据库引用、读者原值、准确预期绑定与原30秒窗口。导入能力只用于历史只读结果分类，不重建阶段WeakMap、延长时间或认证当前用户。新实际SQL连接须在原同一目标的SERIALIZABLE事务中刷新活动快照，确认原framed backend已不存在、无其他backend或prepared事务，持有四共享目录锁，核全部原目录和全部密码，只接受ALL_ORIGINAL或ALL_INSTALLED，混合/漂移拒绝。

实际观察再生成自己的WeakMap证据，供后续可信安装日志接线；复制的公开结果不能冒充新实际观察。观察后仍由调用者ROLLBACK并关闭新连接，不启动任何程序或新HELD，不开放业务入口。过期记录可验证历史，不能再次执行阶段。

验证在新自有PG16保留原20范围，增加真实签名记录、重签结构漂移/绑定拒绝、实际期限过期后的历史只读、新backend对原未关闭连接的拒绝，以及真实子进程分别在COMMIT/ROLLBACK后读取同一私密记录和判断结果。子进程、双输出流及SQL连接正常关闭；原文件身份/字节不变。跨进程事实分类不等于生产安装日志已提交，也不冒充真实网络COMMIT回复未知注入。
