# 新用途用户请求能力与原始身份记录绑定

Gate v2保持新用途、完整企业、明确 action/确认时间、来源/全事实/部署/程序摘要及原30秒窗口。它以已核验的原始记录读取器替代仅返回actor的读取器，从实际令牌、公钥和当时响应取两组记录，使用纯离线消费者重新验证原始语义，并与当前签名权威 head 的准确realm ID/marker绑定；全部前后用户必须相同。

公开证明只新增两组原始记录的摘要，不能含原始令牌、服务令牌或客户端密钥。原始记录仅可通过内部数据桥读取：必须是该模块实际创建的WeakMap V2句柄、对应原意图/来源/操作，已实际再次核验且仍未过期；V1句柄、JSON/证明副本或提供自定义验证方法的对象均拒绝。再次核验更新私密记录，不延长原期限。关闭或原窗口中止时立即关闭原有读取器，中止并等候它们的原请求，再清理自有副本。

这仍是短期、内存中的用户请求和可重建私密材料。持久确认日志必须在原控制/身份事务中消费该原句柄并认证准确的原始记录；当前模块不实现持久防重放，不改SQL凭据、不建立HELD、不批准程序或MQTT。后续协调器须只在新元数据第一次创建的路径初始化确认日志；任何既有意图缺少日志或anchor时须拒绝重建，不能把V1记录静默升级为已确认。

当前运行的Native16使用V1，保持不变。新V2与原始记录接线必须在下一份新完整SOURCE案例中验证并由同案例离线消费者重建全部记录，不能拿V1的用户结论补填这些材料。
