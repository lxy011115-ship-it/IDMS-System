# 同一完整案例的读者安装独立核验

保留已接受的Native17完整64检查参考和全部原独立SQL、权限、材料、身份、轮换、进程正常退休范围。新检查器只能消费Native19原任务的真实终态；66项、1491份源及资源正常退出尚未通过前不得运行消费者或宣称接受。

安装扩展只读同一案例的原SQLite、context、原旧凭据、请求、签名权限头及实际另一次安装后SQL见证。它不导入生产安装日志、协调器、Gate或SQL恢复模块，不重放SQL、登录、传输或安装。分别重算attempt/observation链、原确认和安装前后两组实际身份raw证据、恢复基线与SQL帧、提交前授权锚点和全7库预检绑定；同原全局目录及安装后原始目录逐行比对，只有两个固定原读者的密码验证器可变。

完整新案例目前设计为一次正常提交，扩展据此要求唯一attempt/observation/授权。该接受不覆盖真实网络COMMIT回复未知、重试多尝试、超过30分钟的真实历史经过、新程序批准、新HELD、MQTT应用ACL或业务准入。安装后SQL见证是另一次QA观察；不宣称它与生产恢复观察共享同一事务。原文件字节和身份检查前后保持。

只有新原任务成功后，才按实际report构造第三版检查名参考并准备新独立入口。所有旧检查器和已执行源保留。
