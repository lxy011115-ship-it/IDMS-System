# Windows实际Java环境的明确绑定

首个组件真实执行了编译器和Java子进程，两个原句柄均正常0、双流关闭，但六项检查中五项通过、一项因环境键集合不同失败。实际Java观察多出HOMEDRIVE、HOMEPATH、USERDOMAIN、USERNAME；因此不能宣称首版已验证精确环境。

新V2仍只从空环境构造。Windows显式加入受信启动进程的非空当前用户名/域，以及从新私有home绝对路径派生的HOMEDRIVE/HOMEPATH；要求本地盘符路径。新增Java布尔观察，证明实际环境主目录拼接值等于新私有home，保留原全部固定属性和精确键集合比对，不放过未列入计划的额外环境项。实际宿主身份仍是操作系统信任基，不等于企业当前用户认证。

首版模块、夹具和失败保留，新模块V2、夹具V2及Java观察类V2使用新案例。共享运行目录490文件和87目录前后重新核验；不修改原Native19或网站，不启动读者、守卫、broker或业务，也不据此授予启动权。
