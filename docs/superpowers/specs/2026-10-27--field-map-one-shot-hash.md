# 单次SHA-256调用的等价实现

第一版等价哈希在新物理目标完成原/批/批/原，两个完整批量预检为约27.6秒与27.4秒，七库事实和两份映射原件字节一致、全部资源正常退休。但此前用户确认到旧读者退出已经消耗约3秒，不能仅凭此预检结果宣称原30秒内完整安装可行。

在新不可覆盖V2中，每一层仍计算同一个81字节SHA-256消息，所有输入/节点/左右分支/根/证明校验及错误拒绝保持。仅把createHash+update+digest组合替换为当前已安装Node提供的同步单次hash调用，缓冲区输出继续用于下一层，不缓存哈希结果，不合并层数，不去掉重复完整校验。

先在新独立组件中，以原state-map实现核对全部深度和计数边界、完整树、存在/缺失/空证明以及所有原损坏与异常负例。后续新缓存和捕获版本才可使用它；还需要新物理目标完整七库及原件比较，随后真实新安装案例和同案例独立验收。原写路径、慢算法独立验证器、用户确认及30秒期限均不变。
