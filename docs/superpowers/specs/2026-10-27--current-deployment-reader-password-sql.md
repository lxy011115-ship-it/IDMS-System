# 新用途读者密码的实际SQL事务层

沿用已批准的完整恢复方案。本层供后续可信控制协调器内部调用，不是对外操作入口，也不认证用户或授予程序启动权限。协调器仍须在原control/authority锁内核固定context、真实当前用户能力、持久确认、完整SOURCE与目标事实，并在原期限内保存确定操作后才能调用本层。旧SOURCE、details.review、旧批准及已接受案例不修改。

调用者拥有真实pg.Client、SERIALIZABLE读写事务及准确目标配置。本层核postgres数据库、原bootstrap角色OID、系统标识、目标目录、端点、非standby、无其他客户后端和无prepared事务，锁定共享角色目录。保存全部角色属性、成员关系、数据库目录及全部密码原值；读者必须逐tenant/role/OID/database对应原计划，旧/新值须为独立规范SCRAM验证器。公开观察不包含密码、验证器或可供离线猜测的无密钥摘要。

准备结果是绑定原客户端、真实backend start和事务编号的WeakMap句柄。仅可尝试一次，尝试前消耗；复制、跨事务、关闭、过期及目录/密码漂移均拒绝。原期限最大30秒，之后的检查不得延长。阶段操作只执行指定读者PASSWORD变更，并逐项核所有其他密码、权限属性、成员关系和数据库目录不变。不COMMIT/ROLLBACK，不新建连接或进程，不开LOGIN/业务围栏。

调用者COMMIT或ROLLBACK并关闭原连接后，可用自己新建的真实连接和新事务读取实际状态。读取重新核目标、完整原目录、全部角色密码及无其他后端，仅接受全部原值或全部新值；混合/未知变化拒绝，避免把部分更新当成功。它只分类密码事实，不推断最终业务提交、独立批准或当前用户授权。跨进程持久意图/HMAC journal及真实网络COMMIT回复未知注入仍由后续完整协调器实现。

验证使用全新隔离PostgreSQL16及原拥有生命周期句柄，实际提交/回滚和新连接读取；证明新旧SCRAM登录结果、读权限保持而写操作仍拒绝。负例覆盖假句柄、其他后端、目标/OID/原密码错误、事务切换、单次消耗、原期限、其他密码或权限漂移及混合结果。该组件不替代真实全SOURCE/Control2/Keycloak的新完整案例、程序批准或新HELD。
