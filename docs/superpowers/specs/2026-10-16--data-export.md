# 设备数据筛选导出

用户已授权按现有待办继续开发。本批完成数据管理待办中的查询导出，并修复复用查询发现的SQL范围遗漏。

选择服务端完整筛选CSV：比只导出当前页更符合数据整理需求；比异步任务/对象存储改动小，适合当前本机系统。导出设备台账和批准测点记录，最多10,000行，超过返回422而不静默截断。空结果输出表头。分页参数禁止传入，其他查询参数沿用原校验。

沿用企业身份和受信任工厂/产线/设备范围；有read权限的身份可导出其可查询数据，本批不新增独立导出权限。SQL在单次REPEATABLE READ只读事务中计数和提取，不循环跨事务分页；文件模式使用同一快照查询。汇总、类型/工厂选项、测点定义同样受范围限制。

CSV为UTF-8 BOM、CRLF、双引号转义；文本公式前缀增加单引号，数值保留原数值。包含原批准批次、原行号、来源系统/记录ID、快照摘要，测点另保留定义来源。文件是分析导出，不保证可直接回传上传。响应no-store、nosniff并使用固定ASCII文件名。

页面分别提供按已应用条件导出按钮，使用上次成功查询的筛选，不能把未提交表单内容冒充已应用筛选。按钮遵循忙碌状态；下载错误显示现有错误栏。

实施顺序：扩展有界查询→修复SQL范围一致性→CSV序列化与HTTP路由→页面按钮→单元与真实SQL/OIDC/浏览器回归→更新指南及项目记忆。验证覆盖筛选、超限、CSV危险文本、跨企业/范围、定义参数绑定、空结果和下载。无数据库迁移，不改写历史数据，不代表生产或性能验收。
