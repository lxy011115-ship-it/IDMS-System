# PostgreSQL16角色配置的完整目录核对

新版本保留原SQL事务层的全部约束。实际PG16拒绝在pg_authid读取rolconfig；V2改为读取pg_db_role_setting的完整setdatabase/setrole/setconfig集合，角色主属性仍逐列核对。初始快照、阶段前后及新连接结果观察均比较整套角色配置，包含全局和数据库专属设置，不能省略或改为只查读者的配置。

原V1源、静态通过记录和失败案例不修改；首次运行未进入PG测试，第二次实际PG失败后全部原客户端与原postmaster正常关闭。新V2模块和新测试使用全新自有PG案例，保留原14项并加入两种配置漂移实际负例；每项测试由调用者正常回滚未结束的事务，防止一个失败污染后续测试。原Control/authority/真实用户/持久安装日志、完整SOURCE及网络COMMIT回复未知等后续整合要求不变。
