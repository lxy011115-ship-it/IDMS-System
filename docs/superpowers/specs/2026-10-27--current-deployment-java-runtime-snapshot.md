# 明确启动计划使用的Java运行目录快照

19项收集器覆盖现有已登记工具文件，尚不能表示Java读取的全部运行文件。实际本机JDK目录有490个文件、87个目录，共343823876字节；其中lib/modules为140891368字节，conf/security/java.security和release也不在原七项JDK工具列表中。后续启动计划须同时绑定运行目录，不把19项组件结果扩称为所有动态输入已经覆盖。

新增只读快照器仅接受原生命周期工具WeakMap句柄，从实际工具记录派生javaHome，拒绝任意路径、配置回调或自报批准。枚举这一自包含JDK下全部普通目录和单链接常规文件，限制8192文件、1024目录、单文件512MiB、总2GiB；符号链接和其他文件类型拒绝，避免未经批准扩读运行目录之外。要求release、lib/modules、conf/security/java.security及原七项工具文件全部存在并匹配已验证字节。

逐文件流式摘要和身份前后检查，结束时完整目录集合及所有文件身份再核一次。输出包含原目录、规范相对路径、字节数、摘要和文件身份的规范数据摘要。输出只是描述；不恢复原工具品牌，不认证SOURCE或用户，不授予启动，不包含参数、应用配置或操作系统信任边界。实际启动协调器还须在批准后执行前重算并匹配原计划，配置与环境另行固定。

验证在D盘新私有测试目录复制公开JDK并创建真实原生命周期工具，只修改测试副本的网络配置和新增测试文件；证明这些原七项工具摘要不会发现的变化会改变完整运行目录摘要。另验证假/复制句柄、额外参数、复制描述不能获权，及副本中新建目录链接的拒绝。共享JDK、原Native19和网站不变，不启动读者、守卫、broker或业务。该组件不证明Linux分发包、实际批准后的重核或新用途HELD已完成。
