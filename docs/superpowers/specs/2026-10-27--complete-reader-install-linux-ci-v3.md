工作流V3逐字保留V2的baseline-field-current完整作业，包括8项SCRAM和103项案例测试；保留现有Maven在线预热及同一独立缓存目录。当前部署作业只切新CI入口，不能删掉任一原59项单元测试。在原单元范围后增加完整fast evidence的25项真实文件组件，使用同一新案例的已独立认证PREFLIGHT两份完整map和原始四程序pin，启动新的离线worker，比较原慢重建并拒绝14类完整损坏文件。新增组件仅操作新私有目录与副本，不重放原SQL、OIDC、身份批准或设备传输。

新入口正常返回必须证明Native66、完整独立2案例和1534来源、原64等全部范围、额外安装身份记录24、预检全原件8和进程记录8，以及原59加25共84单元测试真实通过。Native摘要明确只是producer记录；只有全部步骤正常才构造最终CI摘要，不能用提前存在的摘要替代其余步骤。

继续只发布四个明确文件名的有限公开JSON摘要；私有输入、完整日志、PGDATA、令牌、密码、TLS材料和原始控制库不上传。保留固定Action提交、contents只读、不保留Git凭据、原作业不自动取消和原作业超时。新增工作流仅准备，不发布、不触发远端运行，不声明当前Windows案例或精确Linux已经接受。必须先等Native23及同案独立的实际结果，再做精确版本发布和实际Linux验证。
