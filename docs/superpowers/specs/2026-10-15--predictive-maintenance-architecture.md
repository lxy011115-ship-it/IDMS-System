# IDMS 预测维护平台：已批准的方案 A

用户已批准方案 A，并授权安装开发所需软件。沿用现有上传系统，分批实现完整产品，不将 Demo 等同于商用验收。

## 产品与边界

面向离散制造的设备数据管理与预测性维护；同一代码基线支持 SaaS 和私有化。初期保留 CSV/XLSX/JSON 上传，实时只读采集通过边缘服务接入。默认样板为现有 CNC 主轴/轴承；其他设备通过测点和阈值模板配置。

## 模块

- 业务核心：资产/部件/测点、上传校验、权限、报警、工单、审批、知识、模板和追溯。现有 Node.js 服务保持兼容，逐步接入 Java 21 / Spring Boot 3 工作流服务。
- 边缘服务：独立进程，OPC UA 只读订阅和 MQTT 上传，持久化补传队列，来源身份不可跨租户。
- 预测服务：独立进程，使用经校验的时序窗口，输出健康评分、异常、依据、版本与输入摘要。规则/统计模型用于冷启动；训练模型上线前必须完成离线和影子评测。
- 数据：PostgreSQL 业务事务、TimescaleDB 遥测、原文件对象存储；SaaS 企业独立业务数据库，控制面共享。
- 身份：Keycloak OIDC，JWT issuer/audience/签名/过期/tenant 声明验证，后端执行权限。
- 工作流：Flowable；维修提交验证后才允许独立人工关单，失败退回，不由 AI 替代最终责任。
- 模型网关：云/私有模型可配置，超时、低置信度、无效证据或输出冲突进入人工队列。禁止将大模型回答作为物理 RUL 算法。

## 业务数据流

上传/采集 → 数据校验与来源冻结 → 时序存储 → 特征计算 → 异常与健康分析 → 建议 → 工单 → 维修证据 → 独立人工关单 → 故障标签/模型反馈。离线历史上传不宣称为实时在线。

RUL 未具备有效模型和运行工况覆盖时展示“未评估”；线性阈值外推只命名为“预计阈值到达时间”，并注明不等于剩余寿命。

## 安全与一致性

写入幂等键绑定请求摘要；相同键不同输入返回 409。数据、状态和审计原子提交；审批校验版本、冻结摘要、操作者角色和职责分离。审计链跨业务模块统一，重启验证。未配置生产认证或数据库的生产模式拒绝启动。

## 验收证据

后端测试覆盖跨租户、无效输入、重复/乱序、事务回滚、重启恢复、不可自审、AI 不可终审、模型不可用。浏览器验证上传、预测、工单、审批、追溯与移动端。集成测试分别证明 PostgreSQL、OIDC、MQTT、OPC UA、Flowable 与模型网关实际连接；未通过者明确标记。

最终验收包含生产数据库隔离、模板版本冻结与回滚、插件认证、性能/恢复演练、企业试点数据和模型评测。没有凭据或真实设备时保留待验证状态，不降低原目标。
