# 方案 A 增量：企业维修模板与安全治理

沿用已批准的预测维护方案，不改变完整产品目标。此批先让模板对真实工单生效，同时关闭未验收插件执行路径；后续仍需完整插件制品认证/沙箱、领域表、生产安全、现场试点等。

1. 用真实角色重写模板/插件测试：服务层授权、人机边界、不可自审、摘要、未知字段、版本与跨租户。
2. 完成维修模板 schema、草稿修订、内容预览、独立审批、导出导入；不可改已提交内容，驳回/退回也保留原版本。
3. 新工单冻结已发布模板字段；提交验证字段并绑定证据摘要；旧工单不追加虚构模板，新旧版本并行。
4. 活跃网站增加模板中心和声明式字段表单。仅平台注册公钥可证明签名来源；没有制品扫描/隔离则不可认证/运行，旧 signed=true 不作验签结果。
5. 独立 PostgreSQL 库及真实 OIDC 浏览器验证发布、表单、旧版本、事务、重启、导出与手机版；不修改现有企业六批/零工单。
6. 验证后安全重启本机自有平台，检查原企业数据摘要、既有 AI/采集/流程、健康与页面；更新指南与证据。production 门禁保持。

验收不以单元测试绿灯代替真实身份、SQL 与工单行为；插件尚未具备运行时不能宣称已商用。
