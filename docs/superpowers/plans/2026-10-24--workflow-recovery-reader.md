# 独立恢复只读工作流实现顺序

1. 新建独立 Java 应用，只装载 reader 配置、角色权限核验及已有 Flowable 引擎，不改原工作流源。
2. 保留真实 recovery-state 全量查询与命令链核对契约，绑定只读事务和当前 reader 配置；只提供健康及恢复状态 GET。
3. 独立、固定输入构建，核原 jar/source 不变；先完成编译，再用新自有原生任务验证已有非空流程、拒写、漂移、隔离和正常退役。
4. 基于实际引擎结果完成源安装阶段的专用 reader 捕获/冻结/恢复契约。旧恢复目标不补授权、不改变既有基线。
5. 接入真实作者/独立审核的当前身份与完整流程核对，以及持久计划和最终激活；保持未完成项可见。
