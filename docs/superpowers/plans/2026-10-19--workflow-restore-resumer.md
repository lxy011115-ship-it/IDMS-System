# 工作流恢复持久状态机执行计划

1. 核对当前档案/恢复内核/围栏及运行证据，定义独立新模块和catalog/私密意图边界。
2. 实现受限registry/单目标lease、认证请求绑定、角色与ledger原子提交、数据库非事务创建结果对账。
3. 实现固定pg_restore程序/参数/OS身份与准确PG后台的退休；未完成自有目标RESETTING重建，VERIFIED只读重放。
4. 真实非空归档恢复、角色/DB提交边界和native恢复中断的fresh控制器测试，漂移/错误档案拒绝并清理自有资源。
5. 原运行/业务/资料/角色/旧源快照后验、构建类型检查、准确公开证据和项目记忆；保持完整商用目标ACTIVE，不把隔离状态机当原部署或跨服务灾备完成。
