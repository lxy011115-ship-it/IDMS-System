## 执行顺序和证据

1. **基线与依赖锁定**：记录六份原Java源码、BPMN、配置、原JAR和运行绑定；复制到独立候选。使用设计中的稳定Boot 4.1.2/Flowable 8.0.0，Jackson 3至少3.1.8，若实际包含Jackson 2则至少2.21.8。复核MyBatis实际承载的OGNL，不能仅增加独立OGNL依赖。
2. **编译与协议迁移**：迁移Boot JDBC自动配置包、Jackson 3树/reader API及HTTP转换器，消除硬编码引擎版本。保留九个路由、摘要算法、事务及恢复/撤销身份边界。真实Maven构建、打包和依赖树须成功；失败保持原日志和同一进程终态，不用删接口取得通过。
3. **JSON契约**：将现有21个合成向量纳入候选测试，用Node、旧Java和候选结果对照；增加重复字段、缺失/未知字段、record类型强制转换、Unicode及数字边界的HTTP/持久回执检查。遇到兼容差异先定位和修正，不能重签历史回执或放宽非法输入。
4. **显式引擎迁移**：新建双企业隔离数据，包含非空工单、在途终审、原回执、撤销协调及预留。保存全表、角色/权限、BPMN资源及加密档案。维护步骤独立执行官方升级SQL，普通启动仍为validate和`databaseSchemaUpdate=false`；不得自动部署新流程定义。
5. **行为、恢复和回退**：执行全部九路由、维修退回/重新提交/独立终审、错误身份/企业/角色、陈旧版本/证据、原键重试/异摘要、并发及保存失败回滚。升级前、升级后、旧JAR回退均实际还原非空数据；比较全部相关表、任务/历史、回执、定义与权限。回退不自动合并升级后的新业务。
6. **最终依赖与交付**：从真实打包JAR逐库核对全部依赖及内嵌/重定位内容，合并维护者公告与索引筛查，记录未关闭项。确认所有自有实例正常停止及原运行保持；候选源码、报告和验收状态通过脱敏发布流程同步GitHub，正式换版另受完整平台门禁约束。
