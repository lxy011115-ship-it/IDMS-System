# R4 冷镜像实施与验收

1. 实现严格 manifest/key 格式、完整相对路径树和流式认证封装，所有路径/大小/平台/程序构建均有界；沿用已验证私密 I/O 原语。
2. 加入离线源证明、完整目录/文件身份复核和原子发布；实现完整认证后的全新隔离还原，不启动数据库或自动开放业务。
3. 创建独立 PG16 夹具，核对正常关闭，真实跨 schema 表/约束/函数/触发器/OID/角色与非 MVCC 序列恢复；做篡改、错key、源在线、链接/路径和已有目标拒绝、中断后清理。
4. 接入 R4 真实业务与外部流程/认证/队列，形成持久围栏、源终态、密钥/目录与会话/租约刷新准入；恢复旧密文、BLOCKED/HELD、未知控制围栏和 RELEASE_STARTED，证明不重复业务发布。
5. 持久捕获/恢复控制器及中断重入，独立原生进程/连接退休、冻结源与目标漂移检查，之后再规划原系统及云端受控切换。每层保留对应实际证据，不将前层的测试范围扩大为整体验收。
