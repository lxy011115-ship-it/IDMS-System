# 预测读取与工作台（WIP）

使用当前预测 HTTP 配置运行 `node scripts/predictive-console-auth-v4.mjs <private-runtime-file>`，访问 `/predictive/`。HTTP 仍仅使用 QI、READER 和真实 OIDC 共享会话；预测器与 Flowable 材料仅留在独立 worker 配置。此阶段提供独立预测工作台，尚未接入原统一站点或部署到云端。

## 当前接口

所有业务请求必须携带实际共享会话及匹配的 `x-tenant-id`，页面也发送 `x-idms-actor-id`。写请求继续要求同源和 CSRF。GET `/api/v4/predictive/context` 返回当前企业、维护阶段、权限与不含秘密的恢复命名空间。

- `devices?pageSize=1..20&cursor=...`：当前范围批准设备。设备详情 `devices/:code` 返回名称、位置、类别及已脱敏的服务器来源选择器。
- `health?device=...&pageSize=1..20&cursor=...`、`health/:id`：健康列表与当前详情。新快照验证原生分析回执、审计、冻结计划和快照的一致性，返回分析时的输入事实。
- `alerts?device=...&state=...&pageSize=1..20&cursor=...`、`alerts/:id`：告警、关联建议和当前独立复核资格。新告警还核对原申请人及原生证据摘要。
- `devices/:code/jobs?pageSize=1..20&cursor=...`：按事务内写入的设备索引读取任务；结合当前宿主、SQL 作业及原生完成、取消和重试回执。缺宿主的旧任务只标待对账，不自动接管。

健康、告警和设备任务分页绑定身份、角色、范围、部署、预测配置、读取目录、筛选及历史根，30 分钟有效。列表次序及当时的业务行使用固定根；设备可见性仍核当前范围，详情和任务状态重新核对当前资料。每页最多 20 项、最多扫描 36 项，单证明快照最多 256 键/16 MiB；设备资料使用既有有界读取器。没有重新构造全图用于普通列表，但分析写者仍有原完整图成本，不构成容量验收。

## 页面与恢复

设备与分析、告警与复核、提交与恢复三个入口使用真实数据。工程规则评分只支持安排复查，不提供剩余寿命或故障概率。展开证据展示分析时的冻结输入；提交复核时 worker 再核对当前事实和权限。原生激活基线中已有、却缺少新责任证据的历史告警不开放新复核；新生成但缺索引或回执的记录拒绝读取。

提交前保存原 UUID 和请求摘要，回复未确认时查询或关闭原编号，不自动换 UUID 重发。浏览器仅持久保存最多 30 条恢复元数据，不保存复核正文、结果或登录材料；复核草稿仅在当前页面内存中保留。维护暂停或连接暂不可用保留同身份草稿；身份变化清空详情、草稿和当前恢复视图，并拒绝回填旧身份迟到响应。

准备后的取消、持久接受关闭、独立重试和原人重新授权沿用 `predictive-controls-v4-guide.md` 的协议。已开始外部发送时不声称取消成功；独立审核不替代原执行者或创建新流程信封。

## 启用限制

新预测标记带读取版本、来源摘要和激活基线，设备任务/快照索引随原事务写入。旧已激活而缺这些标记的根不会静默升级；旧根与旧无宿主作业迁移仍需独立方案。此 WIP 不应直接替换现有运行系统。

页面基础链路已通过实际浏览器 PKCE，但浏览器中的独立人工重试/原人重新授权、全部复核分支、统一站点多租户共享登录仍待单独验收；对应后台协议已有实际服务检查。一次浏览器异常事件缓冲截断，不能声称整轮 JavaScript 异常完整覆盖为零。
