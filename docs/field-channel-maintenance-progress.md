# 恢复维护只读入口进度

继续完整方案A现场第6项，新增已恢复目标的只读维护核对。正式 prepare-maintenance 只接受已有 VERIFIED 和不可变恢复结果，在原恢复锁下重做认证与编译核验，于同一导出快照生成私密维护清单；不启用应用、迁移或owner登录，不增加权限。清单绑定原恢复操作、目标身份/角色OID、控制围栏、全部事实、结构目录、上下文、独立OIDC配置与30分钟有效期。

独立维护进程只接收目标backup只读凭据和私密认证配置，不接收authority、迁移配置、源账号或归档密钥。实际backup双会话同快照核对35关系，重新检查角色/权限/阶段/结构/根和文件围栏。页面显示恢复摘要、计数与历史已发布引用，明确外部现态和独立审批仍待完成。普通业务、FIELD、审批和激活写入口关闭；当前仅loopback开发入口，production模式拒绝。

真实隔离v3归档、源不可连接、非UTC和迁移ALWAYS恢复后完成准备；真实backup INSERT、nextval、SET ROLE拒绝。专用Keycloak客户端完成实际PKCE浏览器登录，同企业auditor可查看35关系；越企业和operator拒绝。伪造身份头、普通业务Cookie、错企业头、缺CSRF和错Origin均拒绝；每维护session独立HttpOnly Cookie且寿命受清单限制。实际独立CLI只凭reader配置启动，继承demo模式和普通运行配置不影响入口，并确认进程终态。

登录、退出与成功核对写私密HMAC维护日志，目标业务根/审计/序列不变。实际四事件、重启核链、正文篡改拒绝且保留异常文件；单独测试并发追加、错密钥/session、截断行、重排、缺失不重建和Cookie寿命。此日志尚无外部不可回滚锚点，不冒称可以阻止有文件控制权者回滚整段合法历史，也不替代独立终审权威审计。

16项漂移/无效清单拒绝覆盖微秒根、列、约束、索引、触发器、函数、视图名称与定义、default ACL、角色设置/能力、阶段注释、控制标记、错reader和过期清单。实际backup事实读取被真实表锁阻塞后改变控制标记，释放锁后必须拒绝结果。测试仅由隔离QA显式撤销自有改动，维护入口不修复；可逆撤销后完整基线再匹配。视图重新解析即使恢复原SQL也不再匹配旧目录锚点，必须重新受权准备，不放宽清单。

485核心单元、241运行构件/全部脚本语法和类型检查、维护记录专项以及原恢复控制基本回归通过。11个既有恢复生产文件及源归档环境修复保持原字节，原控制器/CLI仅增加维护准备入口；66完整文件契约与十轮双份冻结快照保持。原4010核心及PG/Keycloak进程未重启，原两企业编译权限/角色和无FIELD状态保持。公开双份本文与JSON逐字一致，不包含配置、密钥、备份、SQL、认证正文或原始日志；无新最终证据快照。

完整第6项继续当前OIDC/工作流现态、独立恢复计划和不同主体终审、新注册及证据冻结/离线CLI/全链；第7项受控切换仍待。大库容量、跨宿主、Linux和商业部署验收仍未完成。本阶段未激活、未部署原核心，完整商业目标保持ACTIVE。
