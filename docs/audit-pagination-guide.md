# 审计追溯分页

更新：2026-10-16。继续方案A的分页与活动工作区内存待办。业务迁移4、实体3、payload2、认证schema1保持，无新增DDL或密钥文件；完整商用目标保持进行中。

## 页面使用

进入“批次追溯”才加载审计，其他页面启动不请求完整审计。每页50条，支持搜索事件/对象/操作人/备注，以及对象类型、动作、操作人ID、开始和截止时间的组合筛选。时间输入采用浏览器本机时区，接口传递明确时区的ISO时间。

上一页和下一页沿用同一历史窗口，页号位置与总数仅针对当前授权且匹配筛选的事件。窗口固定30分钟，新事件不会挤动旧页；“刷新最新记录”开启新窗口。“清除筛选”同时清除条件并刷新。对象为数据导入批次时可直接获取批次详情，详情不依赖页面预先加载的最新100批列表。

身份或范围变化、退出及读取异常会清理旧事件和游标。过期或可见范围变化时，页面明确提示刷新，不继续显示旧授权数据，也不把尚未加载或读取失败展示成“哈希链异常”。

## 接口契约

`GET /api/v1/audit`无查询参数时保留完整可见历史的旧契约。出现任一参数后启用分页：

| 参数 | 规则 |
| --- | --- |
| pageSize | 默认50，整数1至200 |
| cursor | 原样传递服务端返回的previousCursor或nextCursor |
| q | 最长160字符，去两端空白并转小写；搜索动作、对象ID/类型、操作人和备注 |
| objectType | 最长80字符，精确匹配，如DATA_IMPORT |
| action | 最长120字符，精确匹配，如IMPORT_COMMITTED |
| actorId | 最长160字符，操作人ID精确匹配 |
| from / to | 带明确时区的ISO时间，含边界；空值清除边界，起始不能晚于截止 |

未知参数、重复参数、控制字符和超长值拒绝。续页时省略条件和pageSize即恢复游标原值；显式改变条件或大小须重新开始，不混用旧游标。

分页返回items、paged、total、pageSize、range、previousCursor、nextCursor、snapshot和规范化filters，并保留chainValid、SERVER_FULL_TENANT_CHAIN和partialView。空结果range为0至0。snapshot只给出捕获及过期时间，不给出企业总数、隐藏计数、原始序号或窗口头。

| HTTP | code | 处理 |
| --- | --- | --- |
| 400 | AUDIT_QUERY_INVALID / AUDIT_QUERY_CHANGED / AUDIT_CURSOR_INVALID | 修正参数或刷新；游标不能转给其他身份或企业 |
| 409 | AUDIT_SCOPE_CHANGED / AUDIT_WINDOW_CHANGED | 当前权限、有效主数据可见集合或窗口锚点变化，刷新最新记录 |
| 410 | AUDIT_CURSOR_EXPIRED | 固定窗口已过期，刷新最新记录 |
| 503 | AUDIT_INTEGRITY | 整条企业链或列绑定不可验证，不返回部分事件 |

401/403仍按正常登录和权限处理；容量429/503及Retry-After沿用原资源准入协议。

## 一致性与授权

每页先走正常鉴权，再进入既有RR+SHARE事务和完整MVCC来源证明。分页提供器从同一快照读取当前头，然后按SQL序号从头扫描到当前头，核对企业、事件ID、序号单调、冗余列、previousHash及历史canonical哈希。隐藏、筛选外、页外以及固定窗口之后的新追加事件也必须验证。SQL没有用LIMIT裁掉待验证历史；验证失败排空驱动查询后整页拒绝。

固定窗口绑定历史头和授权匹配前缀的摘要/总数。新增事件不改变已有页；有效设备工厂或本人任务归属等主数据使旧窗口可见集合改变时，旧游标409。未影响当前窗口可见集合的业务变化不会让所有追溯无谓失效。每次仍依据当前服务端范围判断事件，游标不是认证凭证；声明撤销生效时点仍沿用既有令牌/会话刷新规则。

游标使用已验证的共享认证keyring，经独立HKDF-SHA256用途派生AES-256-GCM子键，绑定部署及issuer/client/audience/Origin对应的认证scope。随机IV和认证标签保护身份、范围、窗口、筛选和锚点；不修改登录会话密文或AAD。相同配置的核心及重启后可续页，保留旧密钥的轮换可继续读旧游标。删除旧密钥后旧游标需刷新。文件Demo采用进程内随机密钥，重启后需刷新。

## 保留内存与验证边界

逐行校验器只保留链头状态、可见摘要/计数和至多pageSize个事件。较旧方向采用环形保留，较新方向保留锚点后最先遇到的N个事件，再倒序返回；前后游标均由当前页生成，不依赖浏览器历史栈。

内存账本新增可幂等归还的部分租用。前一瞬时驱动行在下一行到来时归还，页事件淘汰即归还，失败清理全部页事件，成功页仍计入任务直到响应准备结束。驱动额外结果数组至多1行。额度仍是保守应用权重，不是RSS或容器硬限。

157项单元测试覆盖密码上下文/轮换/篡改、严格游标、全链历史哈希、正反遍历、追加、动态可见集合、隐藏和页外破坏、单页保留、失败租用归还及提供器生命周期；77个运行文件和所有脚本/fixtures语法、TypeScript构建纳入检查。
