## 实际改动

- 当前范围与原 dataScope 对照，包括 SITE 显式全通配的 unrestricted 语义、本人任务、缺失设备 fallback、混合范围导入及受限认证仅本人事件。范围变化后的旧定位器被拒绝，浏览器立即清空已知失效的旧审计视图。
- 窗口与定位器绑定当前授权、部署、目录、根、筛选及有效期。普通追加保持旧窗口；挂起租户、目录变化、授权改变或过期使相关请求失效。每页最多扫描48条、返回20条；空页可以继续翻页。
- 服务器核验原摘要与窗口相邻链接，浏览器独立核验含数字键的规范 JSON 摘要，文本安全展示及完整单事件下载。定位器与事件不进入浏览器恢复存储；迟到请求不跨身份落地。
- 修复同身份维护恢复：没有未完成本人作业时也会继续刷新非 ACTIVE 阶段。实际 AI 应用维护结束后按钮自动恢复，同身份草稿保留。
