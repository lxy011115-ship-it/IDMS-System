# 恢复激活实际材料与对端门槛进度

实际材料检查已接入内部激活事务：固定私密材料清单、实际OPC UA用户认证/只读metadata及有界读取、EDGE/PLATFORM两种证书的真实TLS握手、无客户端证书负例，均与已批准plan-v2完整公开候选一致。四个新生产模块分别处理文件清单、TLS线缆门槛、对端证明和短期检查能力；现有prepare生成attempt-v2，把证据通过attempt摘要封入激活审计与阶段。

私密文件拒绝符号链接/硬链接，读取前后核对文件身份和字节；支持Windows正斜杠绝对路径。每次检查使用独立随机秘密生成材料MAC，不公开密码或可离线猜测的密码摘要。检查能力仅存进程内，最多30秒，最终提交前重新读取全部材料并验证相同MAC、当前身份/作者/流程和权限。实际密码或配置字节变化拒绝并保留原状态。

对端检查不发送MQTT CONNECT/SUBSCRIBE/PUBLISH，既有正常客户端在检查前后继续双向传输。TLS 1.2核对实际发出的客户端证书及服务端Finished；TLS 1.3要求可证明的握手后ticket，并在转发实际ClientHello前阻止PSK、early_data和RFC9149提前ticket请求。真实代理拦住握手后证明时拒绝；若策略允许且服务端支持，另建TLS 1.2连接验证。仅支持TLS 1.3且不给出所需证明的对端仍拒绝。不声称验证主题ACL、在线吊销或外部物理设备身份。

独立实际网络QA覆盖两个TLS版本、错误wire叶证书、可选客户端证书对端、TLS 1.2退回、材料变化、硬链接、held OPC UA读取取消及资源终态，Write/Call均为0。正式归档恢复QA包含4种工单、15个真实outbox命令、源库不可连接、独立审批及当前OIDC/Flowable。材料门槛接入后的实际COMMIT把注册/审计/root/seq/角色/阶段共同提交；提交前真实密码变化和作者撤权均拒绝并回滚。控制者在提交后写结果前被终止，新进程认证归档/目标并允许正常领域业务推进后补回执，重复不写第二次审计。

另一次运行验证Chrome独立审批、真实外部流程推进拒绝、未提交两审计/权限/sequence回滚及同attempt原生围栏恢复，该运行没有提交激活。旧无材料v1内部兼容COMMIT另行验证，不能成为未来正式入口绕过v2的路径。496单元测试与262运行构件/语法/类型通过。54个此前跟踪构件字节保持，8个明确扩展；原生PS/文件内核未变，本轮没有重跑此前8个故障场景，保留其历史证明。原系统运行/数据/角色、431旧源码、66契约及十轮双份冻结复核通过。

总协调器与activate/recover正式操作命令仍待实现，必须强制v2并在幂等回执前验证当前身份与业务流程；wire级COMMIT丢回复、激活后真实新流及旧lease/ACK隔离、离线CLI、冻结证据和受控部署继续。原正式FIELD未部署，无新最终快照。这是内部恢复激活门槛进展，完整商业方案A目标保持ACTIVE。
