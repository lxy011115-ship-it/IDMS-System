每个操作采用“目的—前提—编号步骤—标注截图—预期结果—异常处理”。截图标注引用真实按钮名称，与正文步骤一致。关键状态同时解释含义和下一步，例如“已接收”不能等同于业务完成。高级恢复流程与日常操作分开，便于新用户快速开始。

## 视频脚本与采集要求

录制实际浏览器操作，使用隔离的演示账号和示例设备数据。以一条完整业务为主线：登录 → 导入及复核数据 → 分析和证据核对 → 独立复核建单 → 维修与复测 → 独立审核关闭 → 查询记录与退出。原编号恢复等较长操作作为分章说明，时长按真实流程剪辑，不预先压缩必要步骤。

切换独立审核账号时明确说明职责；等待后台任务时保留必要过程，剪辑或加速必须标注。视频配中文讲解、中文字幕和章节时间点，鼠标指向和字幕需能清楚辨认。不得用静态截图动画、模拟按钮或生成的界面冒充实际操作录像。

登录密码、验证码、会话、访问令牌、私密配置、云控制台资料和真实业务个人信息不得进入交付画面。仅展示演示数据。若最终存在依赖外部条件未能验收的操作，应明确标注实际边界，不以录制替代系统验证。
