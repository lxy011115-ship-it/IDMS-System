# 历史覆盖复核与冻结报告

本轮实现“按当时已知资料复核采样覆盖”，入口为工作台的“历史复核与报告”。这是覆盖分析功能；完整商用方案 A 仍在开发，不能据此宣称现场、模型或生产验收完成。

## 使用

1. 选择批准上传或设备采集，填写当前有权访问的已批准设备编码、起止时间和资料截止时间。时间须带 Z 或明确 UTC 偏移，窗口为左闭右开，最长 31 天。
2. 点击“复核历史覆盖”，检查历史定义、更正记录、日历安排和接入配置依据。每个日历段单独计算槽位，不跨不同间隔或版本平均覆盖率。缺少定义或明确日历时保持未知；声明停产且无计划槽时不适用。
3. 有模板编辑权限的人员填写标题生成冻结草稿。服务端再次读取完整输入并计算，输入摘要与预览不一致会拒绝生成，需重新预览。
4. 有提交权限的人员提交报告，由另一位有终审权限的人打开核验后批准、退回或驳回。生成者和提交者均不能终审；冻结内容不能编辑或重提，资料修订须另建报告。
5. 打开报告会核验完整正文、审批链并独立重算。列表只验证审批摘要，不声称已验证正文。导出完整 JSON 重算包后，可运行 `node scripts/verify-frozen-report.mjs --file <包的路径>` 离线核验。

## 历史证据边界

- 上传定义、资产和测量值按持久的独立批准及提交事件选择截止前有效修订；原批次、更正链、原文件摘要和来源行号保持。截止后的更正不会改写旧复核或冻结报告。
- 采集记录同时满足事件时间在窗口内、接收时间不晚于资料截止，并校验持久接收回执。接入点表从服务端实际观察配置时开始记录；旧版本、空配置移除均留痕。第一次观察之前的点表不可推断，采集复核返回 422。
- `registry_history` 只保存公开接入映射、来源标记和摘要，不保存签名密钥、状态密钥或状态 URL。配置观察是服务器记录，不能代替人工配置审批或现场调试验收。多个实例配置不一致时，已过期实例会拒绝写入，须核对配置后重启。
- 日历读取截止前已发布的生效安排及精确引用的冻结日历。循环日历读取已有 UTC 展开，不因时区数据库升级重新编译。
- 查询、列表、打开、导出以及旧幂等回执重试，均先应用当前身份与设备范围。历史报告不会保留撤权后的访问权。租户管理员和审计员仍按原有企业范围规则授权。
- 资料截止采用持久逻辑事件时间和数据库接收/观察时间；并非物理事务提交时刻，也不是独立可信授时。普通 SHA、包内事件和重算一致仅证明内部一致性，离线工具明确返回 `externalAuthenticity: NOT_PROVEN`，不能证明外部签名或签发者身份。

## 存储、限制与升级

PostgreSQL 迁移 5 仅新增独立追加表 `registry_history` 和 `analysis_report_events`，保留迁移 1–4 的原校验值。应用角色仅可 SELECT/INSERT，两表复用不可变触发器。报告正文只保存在首次生成事件，其后最多追加提交和终审两条事件；不扩大模板目录或主业务快照。

每次复核最多 25,000 条完整输入记录（包括所选历史资产/定义及测量/采集输入），最多 2,048 个测点与日历段组合；分页不缩小计算或摘要范围。超过限制、历史不完整、摘要不一致或资源预算不足均失败，不返回截断成功。仍需完善更大元数据、完整读写和 CPU 资源边界。

旧“数据质量”页的默认当前配置算法保持；其“生效复核”只回查日历，仍标记 `CALENDAR_ONLY`。需要完整定义、记录和点表历史时使用本入口。

备份范围仍为企业业务数据库，包含这两张表。恢复验证必须在全新隔离数据库进行，核验冻结正文及审批事件。该验证不涵盖身份、工作流、边缘缓存、密钥与模型的全服务灾备，不代表 RPO/RTO 验收。

## 核验入口

- `npm test`、`npm run build`：单元、全部运行文件与脚本语法、TypeScript。
- `node scripts/verify-registry-history-sql.mjs`：实际最小角色 PostgreSQL，历史导入/接入链、版本化计算、独立报告、故障及隔离备份恢复。
- `node scripts/verify-analysis-replay.mjs`：隔离数据库与真实 OIDC、MQTT、浏览器，覆盖独立审批、丢响应重试、导出、权限变化、预算、取消和重启。
- `node scripts/verify-analysis-upgrade.mjs --capture|--offline|--live`：原平台专用、不可覆盖的迁移 4→5 保全证据。捕获与离线核验要求原核心已停止；不得将测试数据写入原企业。

接口见 `docs/api/data-upload.openapi.json`。健康标记为 `coverageReplay=asof-all-inputs-v1`、`frozenCoverageReports=append-only-independent-report-v1`、`configurationHistory=observed-registry-chain-v1`。
