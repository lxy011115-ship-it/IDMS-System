# IDMS 备件与采购使用指南

版本：2026-10-30，本地开发版。入口：http://127.0.0.1:4010/?view=spares 。使用现有企业账号登录；本指南不包含账号密码。

本轮新增采购供应商库存闭环，并整理主站导航。采购下单、发票和付款均为人工登记：系统不会向供应商发送订单，不连接银行或执行付款。

### 分页和搜索操作更新

- 上方数字汇总覆盖全部授权资料；下方表格每页30条，点击“上一页/下一页”浏览。搜索框查询该页签全部授权资料，不只查当前页。
- 表单中的备件、仓库、供应商、设备和工单点击“搜索选择”，输入编码或名称后点击“查询”。有更多结果时可以翻页；选中资料不会因后续搜索丢失。保存时重新校验当前权限、启用状态和关联关系。
- 采购单点击“单据详情”单独读取明细和准确金额；分批收货表单独翻页。“相关库存流水/相关票款”进入该采购单的筛选结果，使用“清除筛选”恢复全部授权资料。
- 工单点击“读取净领用”查看该工单的库存领用减退料，按备件和单位分别显示；历史文字“实际使用备件”不自动扣库存。
- 如果翻页时提示资料变化，请重新读取首页。已保存但刷新失败时只重读；提交结果不明时点击“按原请求核对结果”，不要另建同一笔业务。

以上已更新本地主站；完整技术证据和待完成项见[分页说明](spares-paged-query-guide.md)。

## 二、账号职责

| 角色 | 可做事项 |
| --- | --- |
| 企业管理员 tenant-admin / 备件管理员 spare-parts-clerk | 维护档案、采购编制、登记下单、收发退调拨、盘点申请、凭证登记、设备适配 |
| 数据上传员 data-uploader | 创建和提交本人采购申请 |
| 维修人员 maintenance-engineer | 采购申请；本人维修中工单的领料；本人领用的退料和实际更换 |
| 独立终审员 final-approver | 采购、期初、盘点和报损审批 |
| 审计等只读人员 | 查看当前企业及授权范围内资料 |

创建、编辑或提交采购的人员不能批准该单。盘点、期初或报损申请人不能批准本人申请。具有多个角色也不能绕过自审限制。本次没有创建新用户、修改密码或调整现有用户的角色分配。

仓库、供应商、采购和库存按企业及工厂限制；设备领用、适配和工单还需满足设备及任务范围。维修人员必须选择本人负责且处于维修中的同设备工单。

## 三、首次建账

1. 在“供应商”新增编码、名称、联系人、电话和交货期。
2. 在“库存概况”新增仓库，填写工厂编码、仓库编码和库位说明。
3. 在“易损备件”新增编码、名称、规格、品牌、分类、单位、安全库存和参考价，选择是否易损件。
4. 计数单位如只、件、套使用整数；kg、m、L 等计量单位可选择最多三位小数。单位与精度建立后不能编辑，避免历史库存被改成另一种计量口径。
5. 已有实物库存通过“期初建账”填写数量和依据，由另一名终审员批准后入账。普通编辑不能直接改余额，有历史流水的同一备件/仓库不能再次期初建账。

编码只使用字母、数字、点、下划线和短横线。档案支持停用，保留历史引用；停用档案不能继续用于新业务。一个工厂的备件与仓库不能混用其他工厂的档案。

## 四、采购到货

1. 在“采购单”新建申请，选供应商及收货仓库，填写需求日期和说明。
2. 明细逐行选备件、数量及人民币单价。可增加或删除行，每单最多50项。
3. 保存为草稿，在详情中提交审批。
4. 独立终审员打开详情，批准、退回或驳回，并填写意见。退回单可修订后重提；原版本保存在审计事件中。
5. 管理人员在批准后“登记已下单”，可填写外部订单号。此操作只记账，实际供应商下单由人员另行完成。
6. 每次到货从详情“分批验收入库”，选择明细行，填写合格、拒收数量及验收依据。合格数量入库存；拒收单独留痕，不入库。一次可处理一行，分次完成多行验收。
7. 未收齐显示“部分到货”，全部合格数量收齐后显示“已收齐”。需求日期已过且仍在执行的单据显示逾期。
8. 如决定停止后续收货，填写依据关闭采购单；不能删除已发生的采购或收货记录。

收货不能超过该行剩余未收数量。拒收数量不减少后续允许补交的合格数量。网络结果不确定时，保持原表单重试，系统会复用相同请求键避免重复入库；跨页面重新发起新操作前先刷新核对流水。

## 五、领用、退料、供应商退货及调拨

- 领用：在“收发与调拨”选择备件、仓库、设备、数量、用途及工单。库存不足时整笔拒绝，不产生负库存。
- 未用退料：从原领用流水进入，填写数量及依据，回到原仓库。累计退料和已安装数量之和不能超过原领用量。
- 供应商退货：从原采购收货记录进入，填写退供数量及原因。不能超过该收货原合格数量减已退数量，也不能超过当前库存。退供会减少采购净收货量，可另记补货收货；不会改掉原收货事实。
- 调拨：管理人员选择同工厂的调出、调入仓库和数量，一次保存同时完成两条流水。禁止相同仓库调拨、跨工厂混用或负库存。

工单页面展示关联库存净领用量（领用减未用退料）。历史文字备件信息继续保留，它不能自动生成库存流水，也不再次扣库存。

## 六、设备适配和更换周期

先在设备中心“适用备件与更换”进入，或在“设备与更换”新增关系，选择已批准设备、备件、安装位置、每台用量和自然日周期。最近更换日期可以留空。

实际领料后，从领用流水“登记更换”，选择适用安装位置、实际数量、日期和复测依据。系统更新最近实际更换日及下次计划日，**不再次扣库存**。更换日期不能在未来、早于原领用日或已登记的更换日。无周期或实际日期时显示资料不足，不推算设备剩余寿命。

示例：收货10只，领用3只，未用退回1只，实际安装2只；库存为8只，净领用2只，安装记录2只。安装登记不将库存再减至6只。

## 七、盘点与报损

在“盘点与报损”创建申请，选择备件及仓库：盘点填实际清点的总数量，报损填损失数量。系统冻结当时库存数量及流水版本。

独立终审员核实依据后批准，才生成库存差异流水。如申请后发生收发、调拨或其他库存变化，批准会失败并要求重新盘点提交，避免旧盘点结果覆盖新库存。报损不能超过库存。已生效流水不能通过普通编辑覆盖。

## 八、发票及付款凭证

从采购详情“登记票款凭证”进入，选择发票或付款，填写凭证号、人民币金额、日期和依据。票号在同企业同类型内不能重复，累计每类金额不能超过采购单金额。凭证日期不能在未来。

详情分别显示采购金额、净收货金额、已登记发票和已登记付款。退货后付款超过净收货或存在预付款时显示待核对提示，人员需核对实际预付、退货、退款及线下凭证。本期不执行支付，不自动认定财务结清，不自动计算汇率、税费或退款。

## 操作历史与统一权限

新增“操作历史”页签和采购详情关联入口，可按关键词、操作类型及北京时间日期筛选、分页并展开必要变更摘要。岗位权限已进入“系统管理 → 权限与职责”。详细步骤和范围说明见[操作历史与岗位权限](spares-history-and-permissions-guide.md)。

## 九、常见提示

| 提示 | 处理 |
| --- | --- |
| 当前账户没有权限 | 使用对应职责账号，普通用户不能通过页面参数授予自己权限 |
| 单据版本已变化 | 刷新详情，核对他人操作，再提交 |
| 库存不足 / 超过原可退数量 | 核对仓库、已收数量、其他领料、退料及安装记录 |
| 库存已变化，请重新盘点 | 重新清点并新建盘点申请，旧申请可由终审驳回 |
| 设备不在范围 | 先批准设备台账，并核对设备/工单授权及同工厂归属 |
| 模块待初始化 | 部署人员执行专用迁移，不能在页面假装保存成功 |
| 登录过期 | 回到企业登录页使用已有账号重新登录 |

## 十、部署和备份说明（维护人员）

本地项目：`D:\IDMS-System`。新业务位于每个企业 PostgreSQL 数据库的 `idms_spares` schema，包含按业务类型分区的实体、版本、审计事件和幂等回执。没有向原 public 业务集合硬塞备件对象，也没有变更现有 public 表结构。

在项目目录运行：

```powershell
npm run spares:setup
npm run spares:verify
```

初始化脚本使用既有专用迁移配置执行事务DDL，业务应用账号只获必要读写权限，不获建表权限。验证脚本只创建随机命名的隔离测试数据库，完成后删除这些测试库，不写企业业务单据。

现有备份/恢复 npm 命令为 `backup:create`、`backup:restore`。数据库完整自定义格式备份原本未限制 schema，本轮已将 `idms_spares` 加入逐表结构/行数/摘要核对，并在备份与恢复验证中检查企业边界及备件审计链。必须使用**本轮更新后的**脚本；旧的 public 快照或仅业务JSON导出不能代替采购库存备份。

沿用已有私密备份密钥与凭证文件，不在文档、命令输出或截图中公开密码。先恢复到隔离数据库并逐表核对，再按既有部署流程处理授权；不要直接覆盖运行中的企业库。当前验证完成了隔离数据库 dump/restore、分区事实、库存和审计一致性，不代表已完成生产灾备验收。
