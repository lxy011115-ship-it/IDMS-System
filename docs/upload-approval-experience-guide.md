# 上传与审批体验更新

更新日期：2026年10月29日。适用于本地4010主站。

## 上传前

在“数据上传中心”选择数据类型。表单会显示对应模板的前提、填写要点和可展开的示例。先建立并批准设备台账，再建立自定义测点定义，最后上传对应记录。生产、状态、历史维修和质量检验按各自模板填写。

提示中的示例只解释填写方法，不会创建企业数据。下载标准模板后填写真实资料；中文表头选择适用的已发布映射。原文件、字段映射和更正要求仍按既有规则校验。

## 查看下一步

批次列表增加“下一步”列。打开详情后，在顶部查看处理步骤、当前说明和定位按钮：

| 当前状态 | 建议操作 |
| --- | --- |
| AI处理中 | 稍后刷新同一批次，不重复上传 |
| 校验失败 | 定位错误，修正原文件后重新提交 |
| 待人工复核 | 独立人员核对输入及原材料，填写复核依据 |
| 待人工终审 | 独立终审员核对来源和冻结版本后决定 |
| 已退回或驳回 | 阅读审批意见，按意见重新整理材料 |
| 已入库 | 查询业务数据与来源，必要时走显式更正 |

提示会区分本批上传人、独立终审员和无审批权人员。具有审批权限的上传人仍不能自审。定位按钮只滚动、导航或刷新，不会自动批准、切换身份或提交数据。

## 定位校验错误

1. 打开有错误的批次，点击“定位校验错误”。
2. 从“字段”选择标准字段；原表使用中文表头时，清单仍显示原表头和标准字段的对应。
3. 在搜索框填写原行号、错误码或关键词，例如58、UNIT_MISMATCH或单位，点击“筛选错误”。字段与搜索条件同时生效；按回车也可以筛选。
4. 查看原文件行号、字段、错误码、原因及处理建议。“清除筛选”恢复本批已加载错误。
5. 点击“下载完整错误CSV”核查全部错误，再修正原文件。错误清单包含诊断列，不能直接作为上传模板。

错误行数与错误条目数不同：一行可以有多项错误。详情目前加载前100条错误，筛选仅在已加载错误内进行；出现空结果不代表原文件没有其他错误。完整CSV下载保留原有权限检查。

原文件行号不是分页预览页码，CSV多行文本还可能影响物理行位置；系统不会据此猜测跳到哪一页，也不会自动改单位、采样值或审批结果。切换身份、批次或版本后，旧错误筛选会清空。
