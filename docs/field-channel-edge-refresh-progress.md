# 现场通道开发进度：边缘联网刷新与只读撤权

2026-10-17。已将边缘租约SDK、只读联网撤权和安全OPC UA读取包装器接到真实平台接口。448项单元测试、172项运行构件语法/类型检查通过。独立本机HTTP、最小应用角色PostgreSQL、边缘SDK与原生加密OPC UA联合验证通过。原4010未重启或部署新代码，FIELD入口仍关闭。

## 已实现的链路

- 新增`POST /api/v1/field-channel/lease/check`，接受独立HMAC域、挑战和原租约绑定的机器请求。平台在当前受验证根和观察中核对独立批准，再验证原持久签发记录，返回独立Ed25519域签名的短期允许或拒绝状态。状态最多有效2秒，不是新租约，不能用作采集事件或延长旧租约。
- 核对使用当前头锚验证的完整审计读取，检查列/正文/链/最终头一致。有效哈希前缀不足以证明完整，不能通过遗漏最新换键或撤权记录恢复旧授权。此接口在同一快照完成事实和审计核对，不追加审计或改写业务根；保留审计历史受现有工作区预算约束。
- `services/field/lease-client.ts`提供真实联网的`FieldLeaseClient`，自己产生挑战、HMAC认证并验证固定平台公钥。有效租约可复用；250至1000毫秒间隔的后台检查使用只读接口，失败后不自动重新签发。网络失败、签名/挑战/绑定不符、明确拒绝或状态到期都会清除授权并通知取消。
- 签名状态以绝对有效期和本机单调时间双重限制，不从收到响应时重新延长2秒。状态中断后不能靠迟到回复恢复旧租约。实际采集须在有效租约和新鲜允许状态下进行；状态或租约到期时主动通知在途读取取消。
- HTTP传输限定固定机器路径；HTTPS明确验证服务端证书，远程明文、URL凭据、查询片段及任意路径拒绝。没有重定向或自动重试；请求最多4096字节、响应最多8192字节，检查类型和严格UTF8。请求超时、取消和关闭会销毁连接，并等到本机请求close终态才释放活动槽；不把本机连接终态说成远端数据库执行已经停止。
- `LeasedFieldReadOnlyClient`把租约、状态和只读内核组合：新租约和读取身份固定，最终返回后仍复核，返回`idms-leased-field-observation-v1`，不重标已有观测。后台撤权会取消正在等待响应的OPC UA读取；内核仍按实际排空/隔离状态处理，未终态时不能建立替代读取。
- 刷新和核对单次执行，活动槽在调用用户通知之前建立，同步重入不能发起第二个请求。关闭后不新增网络，等待实际在途任务，清理请求密钥副本及通知注册。没有宣称清零Node密码学对象或硬实时终止保证。

## 实际证据

`node scripts/verify-field-edge-http.mjs`在独立QA数据库启动真实主handler和自有回环OPC UA端。通过机器接口取得租约和状态后，SDK完成两个准确批准测点的加密读取；连续读取复用原租约，重复核对不改业务根或审计。人工批准使用实际领域和事务函数建立，未冒称完成OIDC浏览器终审。

联合验证在原生Read响应被保持期间发布明确暂停，后台核对得到拒绝后取消原读取，并等待内核实际终态；新的暂停读取不发起OPC UA请求。显式恢复后获得新租约。保持HTTP核对无法完成时，状态到期同时取消HTTP和OPC UA客户端，确认本机请求/读取实际终态后才继续。

五类实际读取故障为遗漏末尾记录、重复行、错误头、其他企业列及错误哈希。遗漏末尾用例先由另一配置实例观察换键，再在读取时省去那条最新观察；独立头锚使其失败，不能按旧有效前缀批准。所有故障均撤销边缘租约且不写入数据。服务端Write/Call计数均为0，没有生成遥测点，迁移仍1至5；原企业业务/输入/迁移/表数与Acme状态前后相同。

新增单元验证还通过实际HTTP验证响应篡改、旧挑战回复、重定向、超限/坏JSON/坏UTF8、超时实际关连接、预取消零网络、同步重入、关闭及主动到期通知。即使测试进程环境关闭TLS校验，客户端也拒绝不受信任的自签名HTTPS对端。该环境变更仅在隔离测试进程中临时发生，运行代码始终明确要求验证。

旧事务签发HTTP验证和旧`telemetry:verify`实际采集/MQTT/浏览器回归通过。原66个完整文件契约及十轮两份1571文件/每份SHA保持，原4010/core8080、launcher24228、工具会话36787以及PG21684和Keycloak24780保持。

## 尚未完成

这些代码目前是可调用SDK与安全读取包装器，尚未接入正式现场进程的启动/配置、mTLS MQTT和可靠补传。第4项还需结构化策略作者及受当前人类账号范围保护的只读入口；第5至7项仍包括最终mTLS身份审批/注册绑定、新现场协议、SQLite补传、事务接收、冻结证据/全链OIDC浏览器与恢复和受控部署。

核对状态仅证明该平台快照中的当前条件，不是对物理采样值或授时的外部证明。这里的2秒是签名状态最大有效窗，不是网络、数据库响应或进程实时调度SLA；核对来不及、预算不足或事件循环迟滞时读操作失败关闭。完整审计核对、根写和新增租约审计的规模/长期吞吐仍有现有容量边界。正式现场和完整商用方案A验收仍未完成。
