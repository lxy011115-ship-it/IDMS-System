# 平台现场依赖进度

Windows 候选版本通过 34 项测试、31 项实际全栈检查及独立 V4 复核。固定源码 1,229 份，旧已发布 1,007 份保持不变。Linux 工作流已准备，提交后仍需取得实际运行结论。

平台控制器实际持有两处 PostgreSQL、Keycloak、Flowable、预测服务、MQTT broker、含 SITE 的九成员应用组及 edge 的原始句柄。启动按依赖顺序进行，停止先退役 edge 和网站，再关闭 broker、后台服务及数据库。验证覆盖两租户实际 OIDC 上下文、签名事件重放、SQL 在途回滚、独立连接阻止最后数据库停止后的同请求重试、启动中取消和无关实例隔离。

独立复核在最终状态根验证了 89 份证明、12 个已存点及其签名回执覆盖，合并归档和有限 ACK 环，不把环容量当作历史总量。三个数据库目录干净离线，工作流实际正常退役数量为 6。Windows 使用同账户受限令牌，管理员及 PowerUsers 组禁用；当前用户可访问该令牌创建的对象。受限 PG 小型启停和本次整组验证分别有独立运行证据。

前两轮失败报告与源码快照保留：第一轮验证脚本复用过期管理令牌；第二轮 PostgreSQL 拒绝管理员令牌，清理阶段的请求 ID 错配另有原句柄正常退役记录。修订后的验证刷新管理令牌，失败清理沿用已接受的停止请求，继续关闭独立 broker，并保存最初的错误。独立 V3 曾把未启动 edge 的精简状态误作运行状态检查；其失败与冻结字节保留，独立 V4 只在控制器取消且 edge 未 READY 时接受精确六字段终态，已运行实例仍核全部资源标志。原生结果未改动。

进程 READY 与上述 QA 结果不授予现场正式恢复批准。本轮验证仍使用明确的现场激活测试控制；正式独立人工审核、历史数据及签名键迁移、V6 后台过渡、授权消费者及完整系统验收继续。未备案的 idms.xin 只准备服务器候选，不据此进行公网切换。最终中文图文 DOCX/PDF 和真实旁白、字幕 MP4 尚未交付。
