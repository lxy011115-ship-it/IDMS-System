本文件记录平台注册/签发阶段；后续已实现的边缘SDK与联网撤权见[field-channel-edge-refresh-progress.md](field-channel-edge-refresh-progress.md)。整体FIELD链路仍未开放。

## 已接通的开发接口

`POST /api/v1/field-channel/lease`只接受`application/json`、最多4096字节、无查询参数的来源机器认证请求。带浏览器Origin或Cookie的请求拒绝；人工登录身份不代替来源密钥。机器请求使用独立域HMAC-SHA256，严格绑定一次性requestId、企业/edge/设备/映射/公开profile摘要及请求时间，时效30秒；边缘仍只持平台租约验签公钥。

私密配置由`IDMS_FIELD_PLATFORM_CONFIG`指定，格式`idms-field-platform-config-v1`，含相对bundle路径的Ed25519 PKCS8 PEM签发密钥及每企业的通道列表。每通道提供已严格校验的公共profile和独立32字节机器请求密钥文件。未知字段、跨企业/重复源、重复密钥、错算法、额外PEM、路径逃逸及超限文件失败关闭；公共观察不包含密钥、私密路径、端点原文或账户凭据。关闭服务先等待实际活动请求终态，再清理请求密钥快照和资源记账；不声称已清零Node密码学对象或所有底层内存。

现场注册观察使用独立的`FIELD_REGISTRY_OBSERVED`业务审计记录，保存公共profile/摘要、签发公钥标识和机器请求密钥摘要。完整根验证及租户写锁提供完整性与跨实例顺序；观察正文、递增版本、前序观察及摘要另作严格核对。相同配置重启不重复追加。更换任一上述身份或配置后，旧实例的观察不再是当前配置，不能签发租约。此流程复用现有规范化表和追加审计保护，无DDL或权限变更，不修改旧`registry_history`规则。

签发事务先验证当前根、观察、设备/点表定义、准确来源版本及独立通道审批，再查看旧签发记录。新正文绑定确切审计业务时刻；有效期同时受通道租约时限、下一通道条目和下一来源条目边界限制。即使物理映射相同，新的来源生效条目也不能被旧绑定跨越。

签发记录、业务根和审计提交成功后才生成并返回Ed25519签名。提交失败、提交结果不明或请求取消时不返回签名；若提交完成时租约已经到期，也拒绝返回。相同已签请求重试会先核对当前授权，再取回原正文、原租约ID和原到期时间，不延长有效期。暂停、换版或注册观察版本改变后，旧成功记录不能被重新签发。

## 实际验证与边界

`node scripts/verify-field-issuer-http.mjs`启动独立QA数据库和本机HTTP服务，调用真实主handler与最小应用角色事务，验证机器认证/请求体限制、准确审计时钟、当前批准先于缓存、暂停/恢复、换键阻断旧实例、同配置恢复仍改变观察版本、并发重复仅一条签发记录。实际SQL故障覆盖审计追加、提交后核验和根更新，全部回滚且无成功租约。

该脚本还模拟了真实COMMIT成功后响应丢失：第一次HTTP不返回签名，数据库已有且只有一条签发记录，重试从当前验证后的记录取回同一租约。另将COMMIT返回延后至500毫秒租约过期，证明持久审计存在时仍拒绝返回，重试也不续期。公开观察与签发审计均不含真实测试密钥或私密文件名。测试是机器HTTP认证；独立人工审批通过真实事务函数建立，没有冒称完成OIDC浏览器审批。

两组实际安全OPC UA回归通过，包括签名租约守卫、读中撤销/到期、两种加密策略、10种数值及零Write/Call。旧`telemetry:verify`回归也通过，原有采集、MQTT和浏览器流程保持。此前66个完整文件契约、十轮两处快照的1571文件/每份SHA保持。原4010/core8080、launcher24228、工具会话36787及原创建时间/父链、PG21684和Keycloak24780均再次核对不变；原企业业务、输入、迁移和表数量前后相同。

## 下一步

第4项仍未全部完成。需继续边缘真实HTTP刷新与撤权核对、结构化作者和当前范围只读入口，然后接mTLS MQTT、现场签名协议、配置隔离SQLite补传、事务接收及新的冻结证据/全链OIDC浏览器与恢复验证。当前现场注册涵盖OPC公开配置、请求身份和签发身份；mTLS传输身份还须加入最终审批与注册绑定。全部开发格式尚未作为最终现场证据版本冻结。

无配置表示当前实例禁用签发，不会创建现场观察；删除当前实例的环境变量不代表全局撤权。全局暂停使用独立通道策略的明确暂停，或以仍带签发键的配置为该企业显式观察空channels。边缘离线以短期租约到期停读，尚无联网轮询，不声称即时感知远端撤权。租约签名有效不证明物理设备或传感器值，也不覆盖平台每次接收时的当前治理。

后续刷新客户端应复用仍有效的租约，并将只读撤权核对与新增签发审计区分，避免每个采样都追加一份租约。当前根写事务仍加载完整企业状态，租约审计增长受现有工作区预算约束；本轮没有证明长期吞吐、跨服务灾备或完整商用方案A验收。
