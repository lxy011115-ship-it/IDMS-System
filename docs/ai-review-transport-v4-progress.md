## 已验证

- 原 SMT 实际 delta 与 outbox 同事务提交和回滚；autocommit 入队拒绝。两种调用顺序均验证原子性。组合入队按 gate 1/2/4 顺序；实际阻塞 gate1 时确认 AI gate4 尚未持有。
- 同请求 UUID 重放、版本冲突、并发领取只有一个成功、单 fence dispatch 幂等和终态不可修改；实际错误 key、数据库 OID、目录绑定拒绝。
- 入队和结果保存两处 PG COMMIT 回复实际丢失，新连接恢复持久事实。真实 HTTP 回复在发送时断开，同一冻结请求恢复同一缓存回执。
- 无效 HMAC、有效 HMAC 但错误模型清单、永久 HTTP 拒绝均转人工；连续三次网络失败才耗尽网络预算。三次收到有效回执后的保存前中断可进行第 4 次 HTTP 并成功，不误记为三次推理失败。保存前中断是明确阶段注入，未冒称该项为磁盘故障。
- 当前租户不准入和配置指纹变化时不调用 HTTP、不增加 dispatch，任务保留。这里使用受信合成准入夹具，尚非真实 OIDC/租户业务适配器。
- 真实独立 Node 在收到有效回复、保存前 exit0；31 秒后接管、旧 fence 拒绝，再以原 UUID 恢复。主线程实际 Atomics 阻塞 32 秒，独立线程续租成功，其他领取者不能接管。
- APP 无原表/私有函数读取权限，replica 下 IUD/TRUNCATE ALWAYS 守卫仍拒绝；回滚触发器 DDL 后非 MVCC epoch 拒绝旧绑定。
- 独立网关/独立 token/独立 SQLite/合成材料连接原 Ollama `127.0.0.1:11435`；当前清单 `sha256:359d7dd4bcdab3d86b87d73ac27966f4dbb9f5efdfcc75d34a8764a09474fae7`，617 输入 token/75 输出 token，单次网关 duration 1096ms，仅本机观测。疑似指令命中真实网关 POLICY/HUMAN_REQUIRED；无自动批准、无对客户资料推理。
