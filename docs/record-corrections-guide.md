# 已批准数据更正与版本历史

更新：2026-10-16。当前为开发验证能力，完整可商用方案A目标继续进行。

## 操作方法

在设备数据中心的设备、测点记录或定义来源旁点击“查看历史 / 更正”。也可在已提交批次的预览行进入历史。上传专员修改表单字段、填写更正理由并提交；界面显示旧值、新值、旧版本和原记录摘要。另一名终审员核查后独立批准，批准前旧版本继续生效。上传者叠加终审角色也不能自审。

文件批量更正在上传中心选择同类型、同来源的已提交批次，填写理由后上传CSV/XLSX；保留来源记录ID，仅放入需要修改且当前仍有效的记录。JSON接口同时支持更正。普通新增上传仍拒绝同ID不同内容。

更正批准包可“下载完整更正差异表”，包含所有行的逐字段旧值、新值、版本、旧记录摘要、原行号和新快照摘要；页面只预览前20行时，应使用完整差异表及原文件核查。CSV有UTF-8 BOM及公式文本保护，不能直接回传为上传模板。

## 数据规则

- 七类数据均支持更正：设备、测点定义、测点记录、生产、状态区间、维修、质量。
- `supersedesBatchId`引用同企业、同类型、同来源的已提交批次；可以更正其中部分记录，但每条必须仍以该批次为有效版本。不允许混入新增ID、重复ID或无变化行。
- 来源系统、来源记录ID、设备编码保持不变；测点定义的测点编码也不变。更换资产或测点标识应建立新记录，而不是重写原身份。
- 单位、物理范围、设备范围及时间区间等继续按现有校验执行。修改设备/字典必须保证受影响的当前测点记录仍有效；不能用一次字典修改悄悄重解释已有数据。单位转换及跨类型联合更正仍需后续专门流程。
- 旧值、旧批次/物理行号、旧记录摘要、目标版本、理由及新输入绑定接收审计。删除或修改绑定会阻断批准和重启加载。
- 审批时重新检查版本和依赖。两个更正竞争同一旧版本时，先批准者生效，另一批返回409；须读取新有效版本后重新提交。任何行冲突均整批失败。退回/驳回不改变有效版本。

## 历史与有效版本

原`data.records`和原SQL事实表保留首次批准记录。新版本保存在新批次的冻结数据及追加`managed_record_revisions`账本；业务账号只能SELECT/INSERT，不能修改、删除、截断或DDL。更正行、业务快照、审批、审计和幂等同一事务提交。

查询、统计、上传校验、当前测点字典和新工程分析读取已批准有效版本，避免重复计数。历史批次、原文件、既有预测与工单证据不改写；新工程分析摘要包含来源批次/行号，即使数值改回旧值也不会冒用此前版本的分析。数据中心显示当前有效字典，历史字典可从其版本历史追溯；这不等同旧测点记录已拥有当时的字典快照绑定。

CSV导出补充`record_version`和`supersedes_batch_id`。历史接口：

```text
GET /api/v1/data-management/history?dataType=MEASUREMENT&sourceSystem=erp&sourceRecordId=reading-1
GET /api/v1/data-imports/{batchId}/correction-review
POST /api/v1/data-imports
POST /api/v1/data-imports/records
POST /api/v1/data-imports/{batchId}/approval
```

创建请求在原有字段外增加`supersedesBatchId`与`correctionReason`，二者一起提供。审批沿用`expectedVersion`、`snapshotDigest`及人工复核依据。`predecessorBatchId`仍未实现，不要发送。真实身份来自会话/Bearer；写请求继续要求幂等键、关联ID及浏览器Origin/CSRF。历史查询及完整差异表检查可信设备范围；全平台其他模块范围仍需逐项验收。

## PostgreSQL迁移

数据库版本升级到v2，保留v1原校验和和迁移记录，新增追加更正账本及最小权限。原事实、审批、审计和业务快照不重写。只允许独立迁移CLI执行，业务启动不执行DDL。校验和未知或账本损坏时拒绝自动修复。

升级前停止业务连接，使用已有只读备份工具备份并保留恢复密钥，再运行`npm run postgres:migrate`；完整启动脚本也在业务进程前调用独立迁移步骤。迁移账户与业务账户继续分离。更正初次验证时原55432被其他进程占用；后续恢复批次已改用45432并完成两企业备份、v2迁移及原事实核验，见platform-port-recovery-guide.md。不要把直接`npm start`的文件演示模式当作原OIDC平台。

业务库备份验证现在同时校验更正审计绑定及SQL版本账本，隔离恢复覆盖版本历史。仍不包括身份、Flowable、边缘和AI服务的跨服务恢复，不能直接业务切换。
