# 统一审计工作区 v4

新工作区通过同一不可变业务审计链查询认证、资料/模板、AI、采集和其他业务事件，支持筛选、固定窗口分页、事件详情和单事件 JSON 下载。它是隔离 v4 新入口；原运行站点尚未切换。

## 接口与权限

- `GET /api/v4/audit`：可选 objectType、action、actorType、actorId、objectId、correlationId、from、to、pageSize、cursor。每种参数只能出现一次；页大小 1–20。
- `GET /api/v4/audit/events/<eventId>?locator=...`：使用列表返回的事件定位器获取详情。
- `GET /api/v4/audit/events/<eventId>/download?locator=...`：重新鉴权后下载完整单事件 JSON。

客户端必须使用实际 OIDC/SESSION 身份并发送匹配的 x-tenant-id 与 x-idms-actor-id。请求头不能选择数据库或赋予权限。HTTP 延续 QI/READER 和原认证配置，不持业务 APP、AI 根材料或网关 token。

可见性与原 dataScope 对齐：管理员/auditor 等完整企业范围可查看企业事件；被管理员明确授予全部范围的受限角色遵循原系统的 unrestricted 行为。部分站点/产线/设备范围只显示当前和窗口当时都可见的对象；本人任务仍受 assignee 限制。受限认证视图仅本人事件。混合范围导入不可拆开披露，当前租户挂起会立即拒绝旧有效定位器。

导入范围使用当前/历史 console coverage 及按值计数证明，避免为审计范围判断解码原件和全部行。设备缺失时保留原 device-only fallback 规则。其他业务按对象键读取；HTTP 请求不重建 TenantPayload。复杂范围证明超过预算会明确报错，不把未核验事件跳过或当作不可见。

## 筛选与固定窗口

动作、对象类型和执行方类型为精确匹配；编号不支持模糊搜索。from/to 使用规范 UTC 毫秒时间，含边界。界面的本地时间输入由浏览器转换为 UTC；事件保留原业务时间字符串。

每次新查询固定一个根窗口。加密游标和事件定位器有效期30分钟，绑定当前身份/角色/范围、部署、目录、筛选、页大小、根及位置。更换筛选需重新查询。普通追加不改变旧窗口；治理目录变化、权限变化或过期要求刷新，不能由客户端指定任意历史根。

每页最多扫描48条链中事件、返回20条匹配记录。空页仍可能存在后页，界面会提示继续查阅；不能把一页空结果当作完整历史无结果。没有返回全企业匹配计数或依据隐藏数据生成的筛选建议。

## 核验说明与下载

服务器校验原事件摘要、状态映射成员证明及所读窗口内的相邻链链接。浏览器在详情和下载前独立重算原审计规范 JSON 的单事件摘要，包括数字键的词典顺序。错误摘要停止展示/下载。正文仅使用 textContent，不执行事件内 HTML。

受限视图、筛选页和单事件下载**不表示完整全企业链已验证**，也不是第三方公证。审计记录内保存的 AI 回执来自写入时的受信验证；只读查看端没有 AI HMAC token，不宣称在查看时重新验证了模型网关签名。

JSON 下载包含完整事件和服务器核验范围说明。页面最多展示64000个正文字符，超出时明确提示下载完整记录；服务端事件未截断。分页、详情和下载始终重新检查当前权限；客户端身份 epoch/请求 ticket 阻止迟到数据跨身份或覆盖新筛选。事件、游标、定位器和下载内容不写入浏览器恢复存储。

## 维护结束后的恢复

旧冻结界面只在有未完成本人作业时刷新维护状态。AI 后台发布可能已结束，而创建作业早已 COMMITTED；这时旧页面会保持禁用。新版在 phase 不是 ACTIVE 时继续检查状态，恢复后重启按钮而不清空同身份草稿。

验证使用实际 AI 应用 stage 暂停/释放和独立续租，并在真实浏览器对照旧冻结 JS 与新版。它证明了一类确定的维护恢复缺陷；此前只有短摘要的历史点击超时，仍不能断言其具体根因完全相同。

## 入口与验证

新入口：`node scripts/governance-audit-auth-v4.mjs <私密运行配置>`。配置沿用上一阶段 AI 认证控制台，HTTP 与治理 WORKER 分开；AI WORKER 与认证审计投递仍使用已有独立入口。只读审计无需新 SQL schema 或额外写权限。

新读请求复用每请求2048逻辑键/16MiB值预算的无值缓存快照，固定扫描窗口和2MiB响应上限，并复用 SQL/HTTP/内存调度及数据库语句超时。这些是请求约束，不是全局资源配额、吞吐或生产 SLA。

PG 验证对照旧 dataScope、固定窗口与新增事件、详情定位/篡改/失效权限和8MiB带空白填充原件的有界范围读取。UI使用小语义原件，验证真实 Keycloak/产品入口、审计查询/JSON下载、数字键摘要、CSP/XSS、身份与范围变化、实际维护 A/B 和三种宽度。8MiB原件明确含空白填充，不表示8MiB有效业务字段或本轮浏览器容量验收。
