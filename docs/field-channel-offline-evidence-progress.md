# 现场证据导出与离线重算进度

新增正式导出与离线只读校验CLI。平台使用独立用途域Ed25519签名，将完整租户快照、当前与历史注册、租约/准入/审计、选定edge全部点及回执、公共DER和真实ACK/check绑定为有界规范JSON。校验所用公钥及tenant/edge从独立受控信任文件取得，可另固定预期包摘要；不会从包自行建立信任。

实际源2点经完整35关系归档、新目标恢复、真实OIDC/Flowable独立审批和正式激活，SDK及自主边缘进程继续至6点6回执。真实当前全范围auditor执行只读一致快照导出，包含旧/新流、7个实际wire ACK、2个历史签名check。app原权限足够，不增加backup或sequence权限。外租户、限域operator、system-admin拒绝且不创建输出；auditor的AUTHOR/REVIEWER动作拒绝。实际撤销角色后先拒绝身份，原输出字节保持；恢复身份后已有文件仍拒绝覆盖。

停止并清理全部自有业务服务、对端、数据库/角色与身份后，在独立进程运行实际离线CLI。6点6回执/6事件/7ACK/2check全部重算。带独立私密事件键直接重验6个HMAC；默认公共模式报告HMAC覆盖0，不冒充源事件重认证。真实拦截网络与子进程调用，正例和每个负例尝试数均0。规范输入原件在校验期间保持，测试结束清理自有临时业务证据和密钥；公开报告只保存范围、结果与源码摘要。

15类负例覆盖缺点、重复回执、值变更、SQL审计序列、根摘要、跨租户点、未知字段、坏ACK、坏证书、重签并重建全审计链后的错误decision、错误外部信任、外部tenant范围、预期摘要、事件键与非规范JSON。所有情况拒绝，不修复输入。

公共证书历史校验复用既有OPC UA与MQTT内核，原在线路径仍校验实际私钥。500单元、267运行构件/语法/类型及独立实际OPC UA/MQTT负例回归通过；全恢复链15次UA Read、Write/Call均0。原431运行源码、旧jar、原数据/角色、66契约与十轮双份冻结fresh核验保持。

首次集成测试发现自有临时OIDC客户端遗漏auditor scope mapping；仅修正该测试客户端，并增加耗时恢复前的实际PKCE/READ与写权限拒绝预检。没有为生产角色增加权限。

离线签名包无法证明当前数据库/身份、实时peer握手、外部可信时间或物理硬件真实性，包签名本身没有外部防回滚锚。此实现限制32MiB包、2000点/回执、25000审计、256证书，尚不代表大库能力。原正式FIELD未部署；最终证据冻结、受控部署、跨服务灾备/跨宿主/Linux/OS隔离及完整商业目标继续。
