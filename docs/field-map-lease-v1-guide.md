# 当前状态映射中的现场注册与租约

本阶段将现场注册观察、租约审计、请求重放索引与当前站点的状态映射连接。旧 public 表运行时保持原状。维护期使用完整且通过原规则核验的企业历史编译现场运行标记及历史索引；运行期缺少标记时拒绝服务，不能把缺失索引解释为从未签发。V6治理候选将业务、审计、现场准入与现场运行索引一并原子发布。

`FieldMapIssuerV1` 保留原 HMAC 请求、Ed25519 租约/核对消息、准确字段白名单、原始过期时间与只读核对协议。当前注册及准入先于重放查询。注册观察、签发审计和请求索引由一次当前根 CAS 提交；重放原请求复用原租约，修改相同请求ID的内容会被拒绝。仅有平台签名而没有完全匹配的持久签发审计，不能通过核对。注册版本变化后，即使恢复同一公开配置也不能复活旧版本租约。

`FieldMapTransactionsV1` 要求宿主显式提供当前权威检查，没有默认放行。每次操作核对实际数据库/角色OID及固定SQL目录校验，写入前后、COMMIT前和提交确认后检查门禁与取消。客户端回报未知提交时，只按原命令与请求摘要解析原 SQL 回执。签名在提交确认后产生；取消或失败不产生签名。关闭签发器时取消并等待全部自有操作，清除其复制的请求密钥。
