# v4 治理控制台开发进展

本阶段把模板创建、编辑、提交、独立批准与导入创建、独立批准接到真实工作台。原 v2 站点保持运行，新增模块尚未切换原租户。完整商用方案 A 继续开发。

## 实现

- 新增 `/governance/` 工作台：真实 OIDC/共享 PG 会话、文件及映射引用、行与错误分页、原件下载、独立审核、持久作业恢复和重新授权。浏览器只保留恢复键及输入 hash，身份变化清除旧资料并阻止迟到文件提交。
- 新增与业务候选根一同发布的读取投影。摘要使用白名单；范围计数保持旧 dataScope 行为；分页游标绑定当前主体、范围、generation 和过滤。原件先核验全部块及 SHA，再重新授权、流式输出，浏览器再次验 SHA。
- 新增命令接受关闭围栏：与同键入队串行化，未知请求取消确认后迟到请求不能入队。旧 claim 的准备也被 SQL fence 阻止。新发布入口同时核验 console/control anchor，错误回滚整个事务。
- 新维护计划按最多 32 操作分组持久化，小头绑定所有组 hash，恢复时逐组验证。CSV/XLSX 来源规范修正为 MANUAL_FILE，以符合既有映射规则，旧请求 hash 保留用于识别已有同键请求。
