# 备件操作历史与岗位权限

更新：2026-10-30。本地开发版；使用已有企业账号，不在页面分配角色。

## 查询操作历史

进入“备件与采购 → 操作历史”，或打开 http://127.0.0.1:4010/?view=spares&section=history 。

1. 关键词可搜索记录编码、单号、操作者、关联设备编码及页面提供的变更摘要。它不是整份数据库或供应商联系方式检索。
2. 选择操作类型，并按需要填写开始、结束日期。日期按北京时间解释，包含结束日期当天；显示的操作时间也是北京时间。
3. 点击“查询历史”。列表从新到旧显示时间、操作、操作者、工厂、关联记录及变更。展开“新建/更新”查看必要字段的前后值。
4. 每页最多30条。使用“查看更早记录”和“返回较新记录”翻页。修改筛选后重新查询会回到最新一页；“重新读取”按当前筛选重新核验。
5. 采购详情中的“操作历史”会带入该采购单的关联筛选。清空筛选后恢复查看当前范围全部历史。

列表中的标识用于定位原单据，不提供删除或修改历史操作。库存流水、收货记录、实际更换和票款凭证仍遵循原来的不可普通编辑规则。

## 哪些记录可见

每次查询重新核对当前企业、工厂及设备范围，不保留撤权前的查询结果。包含关联设备或工单的事件还须通过当前已批准设备及工单范围检查。查不到记录时先核对筛选和授权范围，不据此判断记录已删除。

接口核验完整审计链，包括当前账号不可见的事件；发现摘要、顺序、关联边界或版本数量异常时拒绝返回。页面只展示必要业务摘要，不返回完整前后快照、供应商联系方式或原始提交请求。当前校验是本库完整性检查，尚非外部公证或独立存证。

## 当前岗位职责

| 已有角色 | 备件能力 |
| --- | --- |
| 企业管理员、备件管理员 | 档案、仓库和供应商维护；采购申请及收货；库存收发调拨、调整申请；设备关联及更换；票款登记 |
| 上传专员 | 编制和提交采购申请 |
| 维修工程师 | 采购申请；授权设备及工单范围内领退料、登记实际更换 |
| 独立终审员 | 采购及库存调整的独立审批；参与制单的人员不能审批本人记录 |
| 平台管理员 | 查询；叠加其他角色仍不获得备件业务写入能力 |
| 其他具备读取权限的人工账号 | 当前授权范围内查询资料和业务历史 |

“系统管理 → 角色权限”展示统一权限目录和当前账号实际生效的权限。职责还受单据状态、版本、库存及独立审批约束；页面有入口不代表任意记录均可操作。机器身份不执行备件写入或查询人工业务历史。票款仅登记，不执行实际支付。

## 异常处理

| 情况 | 处理 |
| --- | --- |
| 暂无记录 | 清空筛选，核对范围及是否已有实际业务；不要为了演示向真实企业造单 |
| 筛选或分页参数无效 | 检查日期顺序，从页面重新查询，不手工拼接旧分页参数 |
| 历史暂无法核验 | 保留提示及请求追踪编号，联系管理员核对审计；不要删除历史绕过检查 |
| 登录过期 / 无权限 | 用已有账号重新登录，必要时由企业管理员按正式流程核对角色与范围 |

## 维护边界与验证

本轮不改变既有用户角色、不增加数据库权限、不新增业务表。使用隔离PostgreSQL测试库验证数值排序、分页、单据/备件/日期/关键词筛选、当前范围、隐藏事件篡改拒绝及完整备份恢复。

新历史页分批读取并只保留一页结果，仍需遍历完整审计链。原备件业务资料的全量读取和10000实体/20000事件边界尚未改造；本页不能代替容量升级或归档方案。正式企业多岗位签收、生产运维与域名部署另行验收。
