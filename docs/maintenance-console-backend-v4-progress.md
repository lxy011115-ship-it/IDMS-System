# 维修控制台后台接线进度

本开发分支已实现维修工单的持久命令队列、当前身份解析、独立后台执行、Flowable 调度、范围读取和最小权限 HTTP/命令行入口。工单界面尚未实现，未合并部署主分支，也未变更原运行站点。

## 已实现和验证

- HTTP 只使用 QI 和 READER；worker 使用业务 APP、加密授权引用及固定 Flowable 配置。沿用真实 OIDC、加密共享会话与认证审计 outbox，拒绝演示身份。
- 命令 UUID/请求摘要去重、未知接受关闭、授权修订、30秒租约及独立线程续租；工单业务回执、审计和 SQL COMMITTED 同事务提交。实际提交回复丢失后解析原回执。
- Flowable 持原执行者授权引用，在发送前、真实响应后及 SQL 应用前重新解析。撤权等待本人重授；独立审核人重试不替换原责任身份。实际引擎提交后授权修订变化可阻止旧 worker 本地应用。
- 持久重试等待为1、2、4、8、16、32秒，最多60秒；七次连接失败转人工。权限拒绝和实际收到有效回执后的本地提交恢复不计网络失败。保持网络可重发、本地一次应用，不声称网络恰好一次。
- 工单列表固定根分页，并检查当前与历史范围/本人任务；游标绑定身份、权限、目录、部署及期限。详情按当前根读取，完成状态另验业务回执和审计。
- `flow_defer_v4` 已保存 UPDATE 的 FOUND 再清理事务上下文；未知或旧授权修订返回false。
