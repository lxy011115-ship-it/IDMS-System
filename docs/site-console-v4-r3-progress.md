# 统一主站 r3（WIP）验证进展

新版统一入口已接入原人接管页面及后台，保留数据与审计、预测与复核、维修工单和共享登录。新增 format 3 配置、运行加载器、HTTP、CLI、站点壳和独立 QA family。启动前核对每个租户的业务/认证绑定和接管 QI 扩展权限；旧 r2、接管后台/UI 源保持逐字不变。原运行实例和云端没有切换。

实际正向验证有 12 项后台检查、12 项浏览器流程及 62 个输入 sourcePins。两租户/两个独立 Flowable 引擎完成真实治理、预测、维修闭环；浏览器采用 S256 PKCE，关闭 direct grant 后实填登录表单。设备本人接管、接受前 HOLD 后重载同控制两次 POST/两次 202 仍一作业/grant1、真正 202 头后截断正文并仅一次 POST 的 GET 恢复、HUMAN 保留原错误后独立重试及原人新会话重授、范围变更和跨标签迟到响应均验证。范围场景先记录企业管理员正确保有企业范围，再仅对本 QA 账号撤管理员职责后验证收紧范围；不能把前一次管理员结果称为拒绝。

真实采集分析取消核验原生回执与审计，释放迟到规则回复不发布结果。第一条 HOLD 分析因网络超时后恢复并完成，另提交一条并及时取消，未将第一条冒充取消。实际 Flowable 已建单但回执摘要被故意改坏后进入 HUMAN，由另一用户独立重试，再由原建单者重登重授；原 actor/command/request/plan/context/外部信封、计划工单编号保持，真实引擎命令总数仍为 6。只读证明与浏览器结果一致。
